# Antigravity への依頼: タイムカードの本番前試験（コピーで行う）

依頼者: chihiro（承認済み 2026-11-08）。作成: Claude。

## やること
Google スプレッドシート「タイムカード_試験用」（本番「タイムカードバックアップ」のコピー。作成済み）の Apps Script に新しい GAS を入れ、
`runReleaseCheck` を実行して、結果（実行ログ全文）を報告してください。
ブラウザは **coretkoenji@gmail.com** でログインした状態で作業します。

## 絶対に守ること
- **本番の「タイムカードバックアップ」と、その Apps Script は開かない・書き換えない・デプロイしない。**
- 作業するのは、名前が「タイムカード_試験用」のスプレッドシートだけ。開いたら、画面上のファイル名が「タイムカード_試験用」であることを毎回確かめる。
- コードは下の「使うコード」をそのまま貼る。中身を書き換えない。
- 迷ったら、作業を止めて chihiro に聞く。

## 使うコード
このリポジトリ（sbsrd3mission/timecard）のブランチ `impl/punch-sync-and-export` の `gas_backup.gs`（コミット 9c4a169 以降）。
PC の作業フォルダで `git fetch origin impl/punch-sync-and-export` をしてから、
`git show origin/impl/punch-sync-and-export:gas_backup.gs` の中身を使う（作業フォルダのブランチは切り替えなくてよい）。

## 手順
1. Google ドライブで「タイムカード_試験用」を開く（ファイル名を確かめる）。
2. 「拡張機能」→「Apps Script」を開く。
3. エディタのコード（コード.gs など）を全部選んで消し、上の `gas_backup.gs` の中身を全部貼り付けて、保存（💾）。
4. 左の「⚙ プロジェクトの設定」→ いちばん下の「スクリプト プロパティ」→「スクリプト プロパティを編集」→「スクリプト プロパティを追加」で、
   プロパティ `MODE`、値 `test` を1つだけ追加して保存（もともとあるプロパティは消さない）。
5. エディタに戻り、上の関数の選び欄で `runReleaseCheck` を選んで「実行」。
   - 「承認が必要です」と出たら: 「権限を確認」→ coretkoenji@gmail.com を選ぶ →「詳細」→「（プロジェクト名）（安全ではないページ）に移動」→「許可」。
6. 下の「実行ログ」の全文をそのまま報告する。最後の行が「全体: 合格」かどうかも書く。
7. ここで止める。ウェブアプリのデプロイ（新しいデプロイ）はまだしない（次の依頼で行う）。
